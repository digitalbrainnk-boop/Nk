# Échantillons vocaux (5 secondes)

Le sélecteur vocal joue `voice-male.mp3`, `voice-female.mp3`, `voice-duo.mp3` et `voice-child.mp3`.
Génère-les une fois avec Suno via Kie.ai :

```bash
KIE_API_KEY=ta_cle npm run samples
```

Sans ces fichiers, un aperçu synthétique du timbre (synthèse vocale du navigateur) est proposé.
