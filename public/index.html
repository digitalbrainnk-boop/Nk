Commandes

Connecter l'agent à mes applications

Deux façons de relier l'agent à tes autres outils. Le plus simple : utilise Make (make.com), Zapier ou n8n, qui savent parler à des milliers d'applications (Google Sheets, Gmail, Agenda, Notion, ta banque…). Tu y crées un scénario qui commence par « Webhook » : il te donne une adresse à coller ici.

1. Prévenir mes applications

À chaque événement choisi, l'agent envoie les informations à l'adresse. Ex : chaque commande payée s'ajoute à ton tableur Google Sheets.

2. Actions que l'agent peut utiliser

L'agent peut appeler ces adresses pendant une conversation, puis répondre au client avec le résultat. Ex : « Vérifier mes disponibilités » (ton agenda), « Enregistrer une commande », « Consulter le catalogue ». Il ne voit que le nom et la description, jamais les clés.

L'agent tourne sur ce téléphone ? Connecte-toi par code

Entre ton numéro WhatsApp avec l'indicatif du pays, sans + ni espaces (ex : Burkina 226XXXXXXXX, Côte d'Ivoire 225XXXXXXXXXX). Le code s'affichera ici, sur cette page (WhatsApp ne l'envoie pas par message). Ensuite, dans WhatsApp → Appareils connectés → Connecter un appareil → Associer avec le numéro de téléphone, puis tape le code.

⚠️ Cette connexion utilise une méthode non officielle. WhatsApp peut bannir les numéros qui envoient des messages automatiques en masse. Pour un usage très intensif, préfère WhatsApp Business Cloud ci-dessous.

Commandes et relances

💰 Vérification des paiements

Quand un client dit avoir payé (ou envoie une capture), l'agent ne compose rien : il te prévient sur WhatsApp avec la capture. Vérifie ton compte, puis réagis à son message avec ton emoji : la chanson est composée et livrée au client en ~10 minutes. Seule TA réaction compte : si le client réagit avec le même emoji, rien ne se passe (protection contre les fausses captures). Tu peux aussi réagir directement sur la capture dans la discussion du client.

L'agent te laisse aussi un message sur ce WhatsApp quand il ne comprend pas quelque chose.

Répondre en vocal

Si ffmpeg est installé (Termux : pkg install ffmpeg), le vocal s'affiche comme une vraie note vocale.

Pour que l'agent parle avec ta voix : crée un compte sur elevenlabs.io (abonnement « Starter » nécessaire pour cloner une voix), va dans Developers → API Keys, crée une clé et colle-la ici. Ensuite enregistre-toi 1 à 2 minutes dans un endroit calme (ou envoie un vocal / fichier audio de toi).

Avec la clé ElevenLabs, l'agent comprend aussi mieux les vocaux des clients.

Comprendre les vocaux des clients

Par défaut, l'agent essaie de transcrire les vocaux avec ta clé Kie.ai (s'il trouve un modèle de transcription chez Kie). Si les vocaux restent « pas compris », ajoute ici une clé Groq gratuite (console.groq.com → API Keys) : c'est rapide et très fiable.
