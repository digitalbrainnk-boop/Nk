1. Importer tes conversations WhatsApp

Sur ton téléphone : ouvre une discussion avec un client → ⋮ / nom du contact → Exporter la discussion → Sans médias. Envoie-toi le fichier puis dépose-le ici (.txt ou .zip). Tu peux en mettre plusieurs d'un coup — plus il y en a, mieux l'agent t'imite.

2. Ce que l'agent a appris

L'agent apprend aussi en continu : quand tu réponds toi-même à un client, ou quand tu corriges un brouillon.

3. Ton profil d'écriture

L'IA analyse tes échanges et rédige un portrait de ta façon d'écrire. Tu peux le retoucher.

WhatsApp (ton numéro)

Connexion comme WhatsApp Web : scanne le QR avec ton téléphone (Réglages → Appareils connectés).

L'agent tourne sur ce téléphone ? Connecte-toi par code

Entre ton numéro WhatsApp avec l'indicatif (ex : 2250700000000). Le code s'affichera ici, sur cette page (WhatsApp ne l'envoie pas par message). Ensuite, dans WhatsApp → Appareils connectés → Connecter un appareil → Associer avec le numéro de téléphone, puis tape le code.

⚠️ Cette connexion utilise une méthode non officielle. WhatsApp peut bannir les numéros qui envoient des messages automatiques en masse. Pour un usage très intensif, préfère WhatsApp Business Cloud ci-dessous.
